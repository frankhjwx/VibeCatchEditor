# 默认 Catch 皮肤

仓库不附带默认皮肤资源；没有皮肤时可正常构建和运行，以基础图形显示对象。

本地可自行放置 `default.osk`，构建时仅在文件存在时复制到输出目录，应用启动时只把 `skin.ini` 和 Catch PNG 安全解压到 `artifacts/skins` 缓存。该路径已被 Git 忽略，不会随源码上传。

工具栏“皮肤…”直接选择 `.osk`，不需要用户手动解压。当前加载 fruit、overlay、fruit-drop 及对应 `@2x` 图片和相关颜色；不加载音效、光标或其他模式资源。

本地使用的 `osu! Default Skin Template (20210821).osk` 仅用于开发验收。皮肤版权归各自作者所有，代码的 MIT 声明不适用于皮肤图片；发布包含本地皮肤的构建前需确认相应资源许可。缺少该包时，针对其实际图片尺寸的测试明确跳过，其他皮肤测试照常运行。
