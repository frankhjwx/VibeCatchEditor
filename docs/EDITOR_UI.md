## 时间—X 与导航

场地 X 为 `0..512`；时间向上递增。扣除标尺后的绘图区变换为：

```text
screenX = left + mapX / 512 * width
screenY = bottom - (timeMs - startMs) * dipPerMs
mapX = (screenX - left) / width * 512
timeMs = startMs + (bottom - screenY) / dipPerMs
```

绘制、命中与拖动共用变换。暂停时滚轮向上浏览较晚时间，中键拖动内容跟随指针；Ctrl + 滚轮缩放时间间距。视图变化不修改文档或撤销历史。

播放线固定在主绘图区距底部 25% 处，即 `lineY = plotBottom − plotHeight × 0.25`。播放和 seek 连续移动内容，AR 还原与 resize 也保持该位置；开始前、结束后允许留白，不因谱面边界挤动播放线。暂停后可以手动平移，下次 seek 或播放恢复固定定位。底部播放头与视口框连续更新。播放绘制通过 `WM_PAINT` 与 `Present(1)` 跟随显示器刷新，没有固定 60 FPS 限制；实际刷新率未作保证。

“还原 AR 比例”按 `440 / preemptMs × plotWidth / 512`恢复游戏下落速度，并将当前时间定位到距底部 25% 的播放线。该模式随宽度及 AR 更新；Ctrl + 滚轮退出到自由缩放。预览隐藏时按钮仍然有效。

AR / CS 范围为 0–10，演示默认 8 / 5，修改进入内容撤销历史。预览按 512:440 等比装入面板，始终使用 AR 下落速度，不跟随主画布自由缩放。两视图用相同 CS 和 PNG 尺寸规则，详见[Catch 绘制与转换](CATCH_RENDERING.md)。

## 图层与实际对象

主画布先画生成对象，再画曲线、锚点和控制柄。选中轨迹为 100% 不透明，未选中轨迹为 50%；“隐藏曲线”隐藏曲线及编辑节点，但保留所有实际 Fruit / Droplet / TinyDroplet / 香蕉。Legacy Slider 显示其原路径对应的时间—X 轨迹，不将随机 tiny 连线当作原路径。选择与图层开关不修改转换数据。

预览的“调试曲线”独立于主画布，默认关闭；打开后先画曲线再画实际对象。对象仅在 `0 ≤ 对象时间 − 当前时间 ≤ preemptMs`内出现。预览跟随音乐或手动定位，不提供接取输入与判定试玩。

普通对象使用白色底图 tint；hyperdash 起跳对象加红色或皮肤配置色的扩大底层标记，包含满足条件的 Droplet。TinyDroplet 和香蕉不参与 hyperdash。香蕉底图、overlay 和几何回退均静态乘 0.6，不实现随机缩放动画。完整旋转、additive 光晕、命中动画和 combo 着色没有复刻。

V/F 对象模式下，点击或框住 slider 任意 Fruit / Droplet / TinyDroplet 即选择整个父 slider，同一父对象只计一次。命中和框选共用皮肤实际范围，包含透明边距及底图/overlay，保留最小点击容差，不作逐像素 alpha 检测；缺失纹理按几何尺寸回退。纯选择不改变文档，隐藏辅助曲线后仍能框选实际对象。

Legacy Slider 选中后，可从属性或右键菜单执行“转换为 VCE Slider”。转换在一个撤销事务中生成时间—X 节点，保留父 ID、源顺序、行程次数和样本信息。转换要求每个 TinyDroplet 能贴合目标轨迹；边界、SV 或 repeat RNG 冲突使转换失败，Legacy Slider 保持不变。实际子对象由轨迹派生，不逐个拖动。

## Fruit 与节拍

吸附滑杆提供每拍 4、5、6、7、8、9、12、16 等分，最右端为 `1/16`。网格间隔为当前红点的 `BeatLengthMs / divisor`，使用局部 offset 和整数格索引计算，红点边界参与吸附，绿点不重置拍格；小节强调使用当前红点 Meter。自由时间关闭吸附，X 保留连续值并限制到场地范围。

选择工具下单击或框选完整父对象，Ctrl 增减选择，拖动任一已选对象会按共同的 X 与时间偏移移动整组。开启吸附时，以所选对象中时间最早的父对象起点为基准吸附，其他对象保持同一时间偏移；关闭吸附时自由移动。双击 VCE Slider 进入其锚点编辑；已选中整条 VCE Slider 时，单击任一锚点也会直接进入并选中该锚点。单击其他对象会退出编辑并直接选择目标，单击空白会退出并清空选择。空白拖动仍可框选当前 VCE Slider 的锚点。

Banana 工具对应 lazer/stable 的 BananaShower（spinner）：左键按当前吸附设置开始时间，右键在更晚时间完成；Esc 或切换工具取消未完成对象。属性区可精确修改开始和结束时间，逐根 banana 的 X 继续由完整谱面 RNG 派生。

场地 `0..512` 两侧各固定保留 54.4 场地单位，对应 CS=0 的 fruit 半径；该留白不随当前 CS 改变。节拍网格横线只画在 `0..512` 内，不进入两侧留白。

切换吸附不移动已有对象。单击已有非网格 fruit 只选择，不重新吸附；实际拖动才修改位置。独立 fruit、曲线锚点使用同一吸附服务。

`Tick ×…`显式修改全图 SliderTickRate，可循环 1、2、3、4、6、8，参与撤销；与编辑分拍吸附独立。绘制草稿期间先完成曲线再改 TickRate。新建及由 Legacy 转换的 VCE Slider 固定要求 TinyDroplet 贴合；Legacy Slider 继续显示原始 RNG 结果。VCE 自动生成 SV 的范围为 0.1–1000。`Tiny 贴合`只影响未带轨迹级策略的旧工程数据。

## 混合段与输入

每段端点时间严格递增，贝塞尔控制点时间非递减，使曲线成为单值 `x(t)`；允许 X 回摆，不允许时间倒退。相邻锚点至少间隔 0.001 ms，控制点 X 限制在 `0..512`。控制柄存相对偏移，拖动锚点带动其柄；分割线性或贝塞尔段保留原形状，不自动新增 tick。

B 使用 VCE Slider 工具：选中已有 VCE Slider 时进入锚点编辑；没有选中时可点击放置无柄点，按住向上拖动拉出方向柄，同一条中混合直线与曲线。编辑已有 VCE Slider 时用属性区“新 Slider”开始另一条。当前锚点使用独立高对比色；只有右键实际命中的锚点才显示曲线/直线转换，远离锚点的曲线位置只显示轨迹操作。行程次数作用于整条 VCE Slider，首 span 的节点和编辑在后续行程复用。

右键轨迹“插入控制点”默认插入无柄点，不保证保持原曲线形状；邻点仍有柄时相邻段可以继续弯曲。原有分割按钮保留线性/贝塞尔的保形分割。控制点、方向柄与角点转换的交互参考 [Adobe 路径编辑说明](https://helpx.adobe.com/photoshop/using/editing-paths.html)，未采用 Adobe 源码。

点击左侧对象列表时，至少两点的草稿先完成，单点草稿取消，再切回对象模式。V/F 空白拖动框选完整对象，B 编辑模式空白拖动框选当前轨迹锚点；Ctrl 点选增减，Ctrl 框选叠加。草稿绘制期间可用 Ctrl 拖动框选已有锚点。框选不放置 fruit、不占撤销记录；Esc 或捕获取消恢复开始前的选择。播放时框选期间暂缓视口跟随，音频继续推进，框选结束后恢复跟随。

对象模式右键“删除”或 Delete 删除整个所选对象集合；锚点模式“删除控制点”或 Delete 删除所选锚点，可包含首尾点。保留点时刻不重排；不足两个点时删除整个 slider。多选成员上的右键菜单保留当前批量选择，每次批量删除为一步撤销。

数值输入隔离画布快捷键，拒绝 NaN、无穷和越界值。错误后可继续修正，不能污染文档或把后续提交写入旧快照。选择、时间导航、缩放、皮肤和图层开关不进入内容撤销栈。

剪贴板在应用内部保存所选独立 fruit、整条 VCE Slider、Legacy Slider 或香蕉雨的深复制集合，不使用系统剪贴板。控制点复制仍以完整父 slider 为单位；粘贴将最早开始时间对齐播放头，保留相对时间、X、几何、柄、repeat 和样本字段，给全部父对象及节点分配新 ID。复制不改变文档，整批剪切和每次粘贴分别形成一步撤销；任一对象非法则整批回滚，活动编辑需先完成或取消。

## 界面语言

顶部语言按钮切换中文与英文，默认中文。应用自有按钮、菜单、属性、状态和错误/转换诊断通过语言资源键读取；切换会刷新诊断缓存，不修改文档或撤销历史。用户文件内容、皮肤名、谱面标题和已有 Name 不自动翻译；系统、第三方异常及资源自举错误不保证由应用完整翻译。英文主表与同键语言 JSON 的维护方式见[本地化维护](LOCALIZATION.md)。

## 皮肤

仓库不附带皮肤；启动时存在本地 `assets/skins/default.osk` 才自动读取，工具栏“皮肤…”可选择 `.osk`。安全导入仅提取 `skin.ini`及 `fruit-*.png`至 `artifacts/skins`。导入错误显示原因，保留已有皮肤。缺失或无效纹理使用基础图形。

支持水果底图/overlay、drop、@2x、配置名称和 hyperdash 颜色。PNG 保持逻辑尺寸和透明边距，每轴最多中心裁剪到 160 逻辑像素，不按面板拉伸。皮肤更换只影响显示，不改变对象或判定。

## 文件、音频与验证

打开谱面加载完整 timing 与关联音频，支持从文件菜单更换 MP3 / OGG / WAV。MP3 在后台连续解码到 PCM 后按采样帧定位；暂停拖动保持暂停，播放拖动保持播放意图。缺失或损坏音频显示错误且允许继续编辑。工程保存段类型、控制柄与行程次数；`.osu` 输出保留 SpanCount 并单独报告回读误差，不能代替工程保存。视频和 storyboard 不加载。

当前验证见 [多选与本地化验收记录](MULTISELECT_LOCALIZATION_ACCEPTANCE.md)。MP3 解码定位修复不等于硬件延迟校准，未完成 stable 客户端对照；自动化坐标与输入测试、离屏渲染不等于跨屏交互或实际听感验收。
